# 小苗 · Codex

**当前分支：`codex/sprout-personality`。** 在移植基线上增加可插拔静态人设、任务场景和热切换，不包含模型生成器。 [三个版本的区别](BRANCHES.md)。

Sprout 的 Codex 适配版。复用 [QingqiShi 的小苗](https://github.com/QingqiShi/claude/tree/main/mods/sprout)像素宠物和 SVG 图表，通过 Codex 管理的本机 stdio 插件提供 MCP App 面板。正式使用不需要启动 HTTP 服务或保留一个终端。

**第一次安装：[看安装教程](INSTALL.md)**，可以直接把安装指令复制给 Codex，也可以跟着终端步骤操作。教程包含打开侧栏、更新和卸载。

**可替换静态人设：[人设说明](PERSONALITY.md)**。人设与个人偏好单独存放；本分支不包含模型生成器。

## 安装到 Codex

需要 Node.js 22.16+（22.x）或 24+，以及支持本地插件的 Codex。仓库包含已打包的 `dist/`，安装和运行不需要 npm 依赖。

```sh
git clone --depth 1 --branch codex/sprout-personality https://github.com/FlyingDoggy/sprout-codex.git
cd sprout-codex
cd mods/sprout-codex
node scripts/install-codex.mjs
```

已有仓库时，使用 [教程里的更新步骤](INSTALL.md#更新)。

安装器把必要的发布文件复制到 `~/.codex/plugins/sources/muyu-sprout/`，注册本地来源，并安装 `sprout-codex@muyu-sprout`。不会复制开发依赖、使用日志或个人数据。已安装插件通过 Codex 缓存加载，更新代码后再次执行安装器即可刷新。

重新加载 Codex 客户端，让其发现新插件。在插件目录的「Muyu · 小苗」来源查看「小苗 · Codex」，在对话中说“打开小苗”或调用 `sprout` skill。插件声明了对话侧面板与全局入口，支持 MCP Apps 的客户端通过宿主桥接展示界面。

**运行方式：** Codex 按需启动 `node …/dist/cli.js mcp`，使用 stdin/stdout 获取数据和 UI 资源；没有监听网页端口。退出 Codex 后无需单独维护守护进程，再次加载插件时会重新启动，宠物状态与统计缓存保存在磁盘。插件进程异常退出时应重新加载插件/客户端；不承诺宿主会在所有版本自动重启异常进程。

原版 Claude 使用 `claude-code` 自有 UI 扩展接口，不能直接移植进 Codex。此处使用 Codex 支持的 MCP App 接口。

## 开发用网页预览

网页仅用于开发调试，停止该进程不会影响正式安装的 stdio 插件。

```sh
node dist/cli.js serve        # http://127.0.0.1:4317，Ctrl+C 停止
node dist/cli.js status       # 只输出汇总 JSON
node dist/cli.js serve --demo # 明确标记为演示数据，不连接真实账号
```

`--port 4318` 可以更改预览端口。HTTP 服务只监听本机回环地址。

真实数据会扫描 `CODEX_HOME`（默认 `~/.codex`）下的 `sessions/` 和 `archived_sessions/`。面板先读取已有汇总，历史导入、额度、GitHub 和价格更新在后台执行。第一次扫描耗时取决于日志大小，随后按文件增量读取；无变化不重写统计缓存。SQLite 保存请求去重索引与文件读取位置，聚合后缓存小型汇总，重新计价无需重读日志。缓存和宠物状态默认写入 `~/.codex/sprout/`。

实时额度需要已登录的 `codex` CLI。GitHub 贡献与合并记录需要 `gh auth login --hostname github.com`。缺少任一项不会阻止本机 Token 统计和宠物交互。

## 其他接入方式

### 直接注册 MCP

在本目录中运行：

```sh
codex mcp add sprout -- node "$PWD/dist/cli.js" mcp
```

这会修改当前 Codex 用户的 MCP 配置。新会话中可以调用 `sprout_status`、`sprout_interact`。移除时运行 `codex mcp remove sprout`。两种方式任选其一，避免重复注册。

MCP Apps 兼容客户端可显示交互面板；已声明对话侧面板与全屏入口。具体宿主是否显示这些入口由客户端决定。CLI 等没有图形界面的宿主仍会得到文本和结构化数据。原版 Claude 的自动弹出、常驻侧栏不直接继承。

0.4.0 增加的 Codex 场景互动继续保留原版的布局、三个按钮和成长门槛：

- 额度紧张时点击天空的云向 Tibo 求雨；读到真实额度恢复后下一次刷新会下雨。求雨只改变宠物，不使用账号重置次数。
- CatGPT 每天来访一次，停留约 90 秒，点击猫听彩蛋；也可以说「叫 CatGPT 来串门」。升级后首次打开约一分钟会来访。

- 右上角显示当前聊天的项目文件夹名，点击打开人设与刷新菜单。优先使用宿主提供的聊天标识定位会话目录，也支持打开工具传入当前 `cwd`；无法识别时显示省略号入口，不显示插件安装目录或其他聊天的项目。
- 本机任务持续两分钟后端茶；计划模式吐槽计划；上下文压缩留纸条；有活跃子 agent 时冒出小芽。识别到测试/检查命令失败后逐次升级吐槽，随后成功会开小花。任务结束和测试通过分别判断。
- 场景事件从本机原生会话记录增量读取，不需要额外 Hook、模型调用或后台服务。面板每 15 秒检查新记录，额度读数仍按一分钟缓存。未知事件不触发；长期无新记录的任务不当作仍在工作。
- 有聊天标识时，反应跟随当前聊天及其子 agent；没有聊天上下文的全局入口汇总本机活跃会话。只保留事件类型、时间、状态、计数与定位当前项目所需的会话标识和目录，不保存命令、输出或对话正文。台词沿用原版嘴臭风格，新增 Codex、Tibo、CatGPT 词库。

## 功能与统计口径

- 宠物、喂水、摸摸、再嘴一句、持久化成长。第一次启动自动导入全部本机历史及归档记录，无需手动补录；相同继承历史去重。成长值独立于 30 天/全部的图表筛选。
- 成长沿用原版场景底部的等级和格数，悬停场景可看累计 Token。保留原版等级阈值：Lv2 为 20B，Lv3 为 35B；已有数十亿 Token 时仍可能处于 Lv1，这是原版门槛而非历史未计入。
- 每日 Token、30 天/全部范围、趋势和使用热力图。
- 输入含缓存命中和缓存写入，输出含推理 Token，各项都不会重复相加。
- 优先按 `token_usage_record.response_id` 去重；旧格式使用累计差值，计数重置后重建基线。分叉使用父会话边界或记录所有者识别继承前缀，无法确认的旧前缀不计作新增用量。
- 额度优先查询 `account/rateLimits/read`，失败时使用最近会话中的未过期读数；超过 15 分钟的读数显示更新时间。按返回的窗口长度显示，不硬编码五小时或一周。
- 预测只对十分钟内的读数显示，是使用节奏估计，不代表服务端承诺。
- GitHub 过去一年贡献、历史合并 PR 和增删行数（跟随 30 天/全部筛选）；每 30 分钟缓存更新。
- 覆盖本机保留的 Codex `.jsonl` 和 `.jsonl.zst` 记录，不等于整个账号或其他设备的用量。删除日志后可统计范围会相应缩小，宠物最高等级保留。
- 日志扫描读取文件，但只保留用量、时间戳、模型、额度、工作事件状态与项目定位信息；不缓存或返回提示词、回复正文、命令输出或 PR 标题。项目名仅用于本机面板。
- 额度查询通过 Codex 自己的登录状态发起，插件不读取或传输登录凭据。本分支不发起模型调用。GitHub 查询通过本机 `gh` 发起。
- 本版没有启用原版 Buddy 手机同步，不向 Buddy 上传数据。

## 官方 API 价格估算

内置从 [OpenAI 官方价格页](https://developers.openai.com/api/docs/pricing)提取的价格快照，包含 Standard、Fast、Batch/Flex、Ultrafast 的可用模型价格。模型按精确名称匹配，日期版模型可匹配对应基础型号。按单次请求输入 Token 区分 272K 上下文门槛，输入、缓存命中、缓存写入、输出分别核算。

档位读取 `thread_settings_applied.thread_settings.service_tier`，缺少该字段的 `turn_context` 不清空已有档位。

运行时每天最多更新一次成功价格快照。网络失败或官网格式变化时保留上次已验证价格；离线也能计算。价格核验日期、来源、模型明细、计价覆盖率和假设保留在结构化数据中，面板不展示这些说明。向官网仅请求公开单价，不发送本机用量。

这是按**当前官网价格回算的 API 等价估值**，不是历史实付金额或订阅账单。日志没有服务档位时按 Standard 估算；缺少单次上下文时按短上下文估算；缓存写入没有时长拆分时采用默认 30 分钟价格。不包含工具调用费用或地区附加费。未知模型/档位保持未知，已知部分以 ≥ 金额显示，全未知显示 —。

如果日志只保留了中途开始的累计快照，首个累计值会落到首个可见事件日期；无法从残缺日志重建更早的逐日分布。按时间判断过期快照，按计数下降识别重置；未来 Codex 格式发生变化时需要更新适配器。

## 可选配置

| 环境变量 | 用途 |
|---|---|
| `SPROUT_CODEX_HOME` | 覆盖 Codex 会话目录；也传给额度查询进程 |
| `SPROUT_DATA_DIR` | 覆盖缓存和宠物状态目录 |
| `SPROUT_CODEX_BIN` | 指定 Codex CLI 可执行文件 |
| `SPROUT_TIMEZONE` | IANA 时区，默认本机时区 |
| `SPROUT_LIVE_QUOTA=0` | 只使用日志里的额度读数 |
| `SPROUT_GITHUB=0` | 不查询 GitHub |
| `SPROUT_PORT` | 本地网页端口，默认 4317 |
| `SPROUT_PRICES_FILE` | 自己维护的模型单价 JSON 文件 |
| `SPROUT_PRICE_REFRESH=0` | 禁止访问官网更新价格，使用本地快照 |

可选自定义价格按每百万 Token 的美元单价覆盖内置模型。格式为 `{ "模型名": { "input": 数字, "cached": 数字, "output": 数字 } }`，可增加 `write`、`long`、`tiers`，类型见 `src/server/pricing.ts`。结构化数据会列出使用自定义单价的模型。更新价格文件后重新加载插件。

## 开发和检查

```sh
npm ci
npm run check
npm run build
npm test
npm run test:codex # 可选：需要 Codex CLI，隔离安装并验证插件启动，不修改个人配置
npm run pricing:update # 从官网更新随发布包附带的单价快照
```

提交源码时同步更新 `dist/cli.js` 与 `dist/ui.html`。两者已打包全部 JavaScript 依赖，供本地插件直接运行。

测试覆盖历史成长导入、Token 去重与计费口径、官网价格表解析和离线回退、长上下文/服务档位、增量日志尾部、归档/截断/删除、额度过期、并发宠物状态、MCP stdio 与资源读取、本地 HTTP 来源检查。

MCP 配置使用相对 `cwd` 和入口路径，已在 Codex CLI 0.143.0 验证。该版本的兼容配置不会展开 Claude 的插件根目录变量，因此不依赖这类变量。

上游原版保留在 `../sprout/`。移植文件和来源见 [NOTICE.md](NOTICE.md)。本仓库其他 Claude 配置属于上游内容；运行 Codex 版不需要执行根目录的 `bootstrap.sh`。
